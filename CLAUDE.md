# CLAUDE.md

Проектный контекст для Claude Code. Подробности — в [docs/DESIGN.md](docs/DESIGN.md).

## Что это
Аудио-управляемая игра «ПРОУН — Заводная орнитология» в мире ПРОУНов Эль
Лисицкого. Один самодостаточный файл `index.html` (Canvas 2D + Web Audio, без
зависимостей). Игрок — сгусток 4 энергий вокруг ядра; вселенная из механизмов-
партитур (необратимые ритмы Мессиана, тембры Рашада Беккера); цель — подняться
на 1000 м, тратя и собирая энергию.

## Файлы
- `index.html` — игра (вся логика инлайн в `<script>`).
- `PHILOSOPHY.md` — манифест движения «Заводная орнитология».
- `docs/DESIGN.md` — дизайн-спека, реализация v3, ориентиры по коду.
- `.claude/launch.json` — конфиг превью (сервер `proun`).

## Запуск / превью
`python -m http.server 4173`, затем `http://localhost:4173`. В Claude Code —
preview-сервер `proun`. Мир детерминирован: `index.html?seed=N` (по умолчанию 137).

## Соглашения
- Никаких зависимостей и сборки — всё в одном HTML-файле, чистый JS/Canvas/WebAudio.
- Палитра Лисицкого и музыкальные таблицы (`MODES`, `VOWELS`, …) — менять осознанно.
- Воспроизводимость через сид; проверять изменения в превью перед коммитом.
