# CLAUDE.md

Проектный контекст. Подробности — в [docs/DESIGN.md](docs/DESIGN.md).

## Что это
Аудио-управляемая игра «ПРОУН — Заводная орнитология» в мире ПРОУНов Эль
Лисицкого. Игра построена на современной PWA архитектуре: монорепозиторий с
пакетами `@proun/engine` (независимый игровой движок, TypeScript, Canvas 2D + Web Audio)
и `app` (клиентское UI приложение на React + Vite). Игрок — сгусток 4 энергий вокруг ядра; 
вселенная из механизмов-партитур (необратимые ритмы Мессиана, тембры Рашада Беккера); 
цель — подняться на 1000 м, тратя и собирая энергию.

## Структура
- `packages/engine/src` — ядро игры, разделенное на модули: `audio`, `core`, `physics`, `renderer`, `world`.
- `packages/app/src` — PWA интерфейс (React компоненты, HUD, настройки, хук `useEngine`).
- `PHILOSOPHY.md` — манифест движения «Заводная орнитология».
- `docs/DESIGN.md` — дизайн-спецификация, реализация, ориентиры по коду.

## Запуск / превью
1. `npm install`
2. `npm run dev --workspace=app`
3. Открыть `http://localhost:5173`.

Мир детерминирован. Изменять физические константы и сид можно на лету через панель настроек в UI.

## Соглашения
- **Модульность:** Игровой движок (`engine`) не должен зависеть от React. Он принимает лишь `HTMLCanvasElement` на вход.
- **Интерфейс:** Вся UI-обвязка (HUD, высотомер, баки, меню, настройки) реализуется строго в React.
- **Стилистика:** Палитра Лисицкого и музыкальные таблицы (`MODES`, `VOWELS`, …) — менять осознанно.
- **Производительность:** `Renderer` и `GameLoop` должны работать без лишних аллокаций. Хуки React (`useEngine`) подписываются на состояние движка через RequestAnimationFrame.
