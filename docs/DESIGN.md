# ПРОУН — проектная память / Design notes

Сохранённый контекст проекта, перенесённый из памяти Claude Code, чтобы работа
продолжалась с любого компьютера. Это «точка во времени» — при расхождении
сверяйтесь с актуальным `index.html`.

---

## Концепция

Аудио-управляемая игра («Acoustic Ludology, Adaptive Audio Design») в визуальном
мире ПРОУНов Эль Лисицкого. Изначально игра являлась одним самодостаточным файлом,
но теперь была переписана в современную **PWA архитектуру (монорепозиторий)**:
движок `@proun/engine` на чистом TypeScript (Canvas 2D + Web Audio) и обвязка 
на React + Vite в пакете `app`.

## Дизайн-спецификация пользователя (исходное видение)

- **Игрок** = ядро + 4 энергии, вращающиеся вокруг него. У каждой энергии своё
  настроение, цвет, притяжение, звук. Энергии притягиваются к Объектам
  вселенной, соответствующим их настроению/цвету. Вращение энергий — это и есть
  звук игрока; чем полнее бак энергии, тем **медленнее** она вращается и тем
  медленнее её звуковой ритм. При ускорении игрок издаёт звуки, огибающие которых
  следуют за velocity.
- **Объекты** = механизмы (часовые / как солнечная система) из форм (кольца-
  орбиты, синусы, шарики, квадраты…). Движение каждой формы рождает звук; объект
  целиком звучит как музыкальный механизм. Объекты испускают частицы, летящие по
  орбитам векторного поля; глобальное поле = смешанная сумма полей всех объектов.
  Игрок собирает частицы в 4 бака; полнее бак ⇒ сильнее притяжение к родным
  объектам.
- Объекты разбросаны хаотично, но **плотнее внизу** мира, реже выше (вертикальный
  градиент плотности).
- **Взаимодействие:** в радиусе тяготения объекта родственная энергия тянет
  игрока; объект **не может** затащить игрока в центр — игрок выходит на орбиту
  как спутник и может быть перехвачен другим объектом. Игрок также притягивает
  формы объектов, искажая их орбиты. По умолчанию игрок всегда дрейфует;
  WASD/стрелки/геймпад дают импульс для побега.

## Принятые решения по реализации

- Соответствие энергий: красный=квадрат, чернильный/чёрный=круг, охра=клин,
  синий=луч.
- Палитра Лисицкого: бумага `#E7DFCC`, чернила `#1E1B16`, красный `#BF3B2B`,
  охра `#C99B3F`, синий `#3F5666`.
- Мир процедурный, разбит на чанки.

## v3 — «Заводная орнитология» (Clockwork Ornithology)

Манифест движения: [../PHILOSOPHY.md](../PHILOSOPHY.md).

### Звук (тембры Рашада Беккера)
- Голос «существа»: пила → tanh-волнообразователь → **две** движущиеся форманты
  (bandpass) на каждую энергию; вибрато разгоняется (3.4→6.8 Гц); тритоновые
  глиссанди.
- Шина даб-задержки с фильтрованной обратной связью; сухой тёмный реверб ~1.35 с;
  перебивки через дакинг всей шины (`bus`).

### Ритм (Трактат Мессиана)
- Лады ограниченной транспозиции 2/3/6/5 — по одному на энергию; `ROOT = 36.708`
  (D1).
- Каждое кольцо механизма = **необратимый** (палиндромный) ритм `talea`,
  нарисованный бусинами на кольце; форма/размер бусины = длительность.
- **Изоритмия:** длина `colorSeq` взаимно проста с `talea`.
- **Ритмические персонажи:** кольца дышат темпом ×1.0595 за цикл в диапазоне
  0.63–1.6.
- Добавленная длительность 1.5 = форшлаг-орнамент + волнистое кольцо.
- Синяя энергия играет птичьи росчерки (style-oiseau).

### Планировщик и события
- Позиция кольца **без состояния** — функция аудио-часов + упреждение 130 мс,
  с точностью до сэмпла; визуальные вспышки из той же очереди событий.
- События (захват/перехват/отпускание орбиты, столкновение с ядром) запускают:
  стробоскопы, пост-эффект слайс-искажения с хроматическими призраками,
  заикание времени 55–70 мс, ударные кольца, дакинг звука.

### Геймплей
- Цель — подняться на **1000 м** (`SUMMIT_Y = spawn − 10000`, 10 px = 1 м).
- Тяга жжёт **2.1** топлива/с, расходуется пропорционально из 4 баков
  (сумма максимум 48 ≈ 800 м подъёма — нужно собирать/использовать пращи).
- Встречный поток `(40 + 1080·prog^1.55)·gust` крепнет с высотой.
- Пустые баки → тяга 0.28; полные баки сильнее тянут в орбиты (напряжение);
  тангенциальная тяга орбиты 420 = бесплатные пращи.
- `R` — рестарт; победа = тутти «аккорд резонанса» по всем 4 ладам + финальный
  оверлей со временем восхождения.
- Сид мира: `index.html?seed=N` (по умолчанию 137), показан в HUD.

### Статус проверки (на момент v3)
Полная экономика, события, победа/рестарт, планирование в реальном времени
(~7 нот/с возле 3 механизмов), без ошибок в консоли.

## Ориентиры по коду (для будущих правок)

Проект использует архитектуру монорепозитория. Вся бизнес-логика вынесена в библиотеку, а рендеринг UI — в React.

### Монорепозиторий
- `packages/engine/src/...` — Игровой движок (TypeScript). Не зависит от DOM, инкапсулирует Canvas контекст и AudioContext.
- `packages/app/src/...` — Клиентское приложение PWA (React + Vite).

### Ключевые модули (`packages/engine/src/`)
- `world/constants.ts` — музыкальные таблицы (`ROOT`, `MODES`, `OCT`, `VOWELS`, `DRIVE`) и константы окружения (`SPAWN`, `SUMMIT_Y`).
- `world/generator.ts` — генерация механизма-партитуры (кольца, `talea`, изоритмия). Процедурный мир через сиды.
- `audio/audio.ts` — синтез голоса-«существа», планировщик по аудио-часам (`scheduleRing`), птичьи росчерки (`birdBurst`).
- `physics/update.ts` — экономика восхождения, встречный ветер, гравитационные перехваты и столкновения.
- `physics/constants.ts` — физические константы притяжения, трения и орбиталей (выставлены как `let` для настройки на лету).
- `renderer/renderer.ts` — рендер игрового мира и миникарты (без HUD).
- `core/engine.ts` — главный цикл `ProunEngine`, реакция на события, связь подсистем.

### Интерфейс (`packages/app/src/`)
- `hooks/useEngine.ts` — мост между классом движка и React, использующий `requestAnimationFrame` для извлечения состояния.
- `components/HUD.tsx` — высотомер, баки энергии и индикация ветра.
- `components/SettingsPanel.tsx` — панель ползунков для динамической настройки физики в реальном времени.
