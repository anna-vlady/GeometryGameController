# ПРОУН — Заводная орнитология / Clockwork Ornithology

Аудио-управляемая мультиплеерная игра в визуальном мире ПРОУНов Эль Лисицкого. Игрок — сгусток четырёх энергий, вращающихся вокруг ядра; вселенная сделана из механизмов-партитур, чьи кольца — необратимые ритмы Мессиана, а голоса — формантные «существа» в духе Рашада Беккера. Цель — подняться на 1000 метров сквозь крепнущий встречный поток, тратя и собирая энергию.

## 🚀 Быстрый запуск

Проект представляет собой монорепозиторий (`npm workspaces`), разделенный на физико-звуковой движок (`@proun/engine`), веб-приложение на React (`app`), мультиплеерный WebSocket-сервер (`server`) и интегрированный мобильный тач-джойстик (`GeometryGameController`).

### 1. Локальный запуск на ПК и Смартфонах в Wi-Fi сети

Для работы потребуется [Node.js](https://nodejs.org/) (версия 18+).

```bash
# 1. Установите зависимости
npm install

# 2. Запустите WebSocket-сервер мультиплеера и джойстиков
node packages/server/src/index.js

# 3. В другом терминале запустите сервер разработки Vite с доступом по Wi-Fi
npm run dev --workspace=app -- --host 0.0.0.0
```

- **Игра на ПК:** Откройте `http://localhost:5173/` (или `http://localhost:5173/game`)
- **Мобильный веб-джойстик:** Откройте со смартфона по локальному IP вашей сети:  
  👉 `http://192.168.1.203:5173/controller` *(или `http://localhost:5173/controller` на ПК)*
- **Страница настроек джойстика:** `http://localhost:5173/controller-settings`

## 🎮 Управление & Мобильный Веб-Джойстик

### Варианты Управления:

1. **Клавиатура & Мышь (ПК):**
   - `WASD` / Стрелки / Геймпад — импульс тяги
   - `J` (PATA) / `K` (PON) — отбивание ритма Patapon (`J-J-J-K`)
   - `M` — вкл/выкл звук | `R` — заново
2. **Мобильный Веб-Джойстик (`GeometryGameController`):**
   - Доступен по адресу `/controller` (1-в-1 оригинальный векторный 2D-дизайн).
   - **Упрощенный выбор в 1 клик:** Кнопки `🔴 ИГРОК 1`, `⬛ ИГРОК 2`, `🟡 ИГРОК 3`, `🔵 ИГРОК 4` для моментального подключения.
   - **Универсальные Pointer Events:** Стик реагирует и на движения пальцем на смартфонах, и на зажатие кнопки мыши на ПК.
   - **Кнопки A (PATA) & B (PON):** Тактильный виброотклик Haptics на смартфоне.

## 🔥 Новые Возможности & Наработки (Последние Обновления)

### 🤝 1. Мультиплеер & Кооперативный Компас (`Peer Pilot Compass`)
- Синхронизация нескольких пилотов в реальном времени с сглаживанием движения (`anti-jitter interpolation`).
- **HUD-Компас сожительства пилотов:** Верхний индикатор отображает имя ближайшего игрока, точное расстояние в метрах и динамическую стрелку пеленга (`➔`), позволяя игрокам легко находить друг друга в открытом пространстве.

### 🧲 2. Физика Захвата Частиц Многоугольником 4 Энергий & Магнетизм
- **Захват всей фигурой 4 орбит:** Зона сбора расширена с маленькой круглой точки до **выпуклого многоугольника, вписанного между 4 вращающимися орбитальными энергиями игрока**.
- **Магнитное притяжение (Magnetic Pull):** Частицы вблизи корабля автоматически притягиваются к орбитам энергий.
- **В 3 раза больше частиц:** Базовая плотность частиц `partN` у всех звучащих конструкций увеличена до 30–80 штук.
- **Фейдер плотности:** В панели «Регуляторы» добавлен слайдер **«Плотность частиц: 20% – 300%»**.

### 📐 3. Оптимизированный HUD & Правый Вертикальный Высотомер (`Altimeter`)
- **Чистый центр экрана:** Плашка ввода ритма и выбивания комбо `PATA PATA PATA PON` перенесена в **левый верхний угол**, не перекрывая обзор полёта.
- **Боковой вертикальный высотомер:** В правом краю экрана отображается супрематическая шкала высоты с плавающим маркером корабля и цифровым счетчиком метров от Старта (`-2600м`) до Вершины (`0м`).

### 📱 4. Страница Настроек Контроллера (`ControllerSettings.tsx`)
- Страница `/controller-settings` содержит:
  - Генератор и ввод PIN-кодов комнат.
  - **Интерактивный 2D-тестер ввода:** Живой визуальный отклик работы стика и кнопок A/B прямо на странице настроек.

## 🌐 Деплой на Vercel & Render

1. **Фронтенд (Vercel):**  
   Репозиторий подключен к Vercel. `vercel.json` автоматически собирает клиент из `packages/app`.
2. **WebSocket-Сервер (Render / Railway):**  
   Запустите `node packages/server/src/index.js` на любом хостинге сокетов (Render/Railway). В `packages/app` укажите переменной `VITE_WS_URL=wss://your-server.onrender.com`.
