# ПРОУН — Заводная орнитология / Clockwork Ornithology

Аудио-управляемая игра в визуальном мире ПРОУНов Эль Лисицкого. Игрок —
сгусток четырёх энергий, вращающихся вокруг ядра; вселенная сделана из
механизмов-партитур, чьи кольца — необратимые ритмы Мессиана, а голоса —
формантные «существа» в духе Рашада Беккера. Цель — подняться на 1000 метров
сквозь крепнущий встречный поток, тратя и собирая энергию.

→ Манифест движения: [PHILOSOPHY.md](PHILOSOPHY.md)

## Запуск

Проект представляет собой monorepo, разделенный на физический/аудио движок (`@proun/engine`) и PWA UI оболочку на React (`app`).

Для запуска вам потребуется [Node.js](https://nodejs.org/) (рекомендуется версия 18+).

```bash
# 1. Установите зависимости
npm install

# 2. Запустите локальный сервер разработки
npm run dev
```

Откройте `http://localhost:5173/` в вашем браузере. Вы сможете на лету настраивать константы физического движка через боковую панель настроек.

Для сборки готового к продакшену PWA приложения используйте:
```bash
npm run build
npm run preview
```

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки / геймпад | импульс (тяга жжёт энергию) |
| `M` | звук вкл/выкл |
| `R` | начать восхождение заново |

Мир детерминирован сидом: `index.html?seed=N` (по умолчанию 137; показан в углу).

## Что внутри

- **Звук (Рашад Беккер):** пила → tanh-волнообразователь → две движущиеся
  форманты на каждую энергию, разгоняющееся вибрато, тритоновые глиссанди,
  даб-задержка с фильтрованной обратной связью, перебивки-дакинг.
- **Ритм (Трактат Мессиана):** кольца механизмов — необратимые (палиндромные)
  ритмы, бусины = длительности; изоритмия (взаимно простые циклы высот и
  длительностей); ритмические персонажи дышат темпом; добавленная длительность —
  форшлаг и волнистая орбита; лады ограниченной транспозиции по одному на
  энергию; синяя поёт стилем uазо (птицы).
- **Реакция среды:** захват/перехват орбиты и столкновения дают стробоскопы,
  волны искажений с хроматическими призраками, заикание времени, ударные кольца.
- **Геймплей:** восхождение на 1000 м; топливо тратится на тягу и собирается
  из частиц векторных полей; орбиты механизмов — бесплатные пращи; вершина —
  тутти-аккорд резонанса.
